## 四、SQL 关键点（确保与开发技术文档对齐）

| 项 | 决策 | 出处 |
|---|---|---|
| 数据库 | MySQL 8.0+，使用 `utf8mb4` / `utf8mb4_unicode_ci` | ADR-002 / §2.1.3 |
| 金额 | 整型分（`BIGINT`） | §2.1.3 |
| 时间 | `DATETIME(3)` 毫秒精度 | §2.1.2 |
| 软删除 | `deleted_at` + `is_deleted` 双字段 | §2.1.4 |
| 主键 | `BIGINT UNSIGNED AUTO_INCREMENT` | §2.1.1 |
| ENUM | 仅用于明确有限的状态（订单状态、投递阶段） | §2.4.2/2.4.3 |
| JSON | 用于少量可变结构（如 `extra_specs`、`analytics`），优先 TEXT | §2.3 |
| FULLTEXT | 仅 products.name + news.title + cases.title | §2.4.1 |
| CHECK | MySQL 8.0+ 原生支持 | §2.3 审核修正 |
| 触发器 | 仅用于 `order_items → orders.total_cents` 同步 | §2.6 |

## 七、撰写策略

1. **章节拆分**：第 4 章数据字典 + 第 5 章 DDL 是体力活，**每 2~3 张表一个段落**，避免单次写入过大
2. **SQL 验证**：每张表 DDL 写完后**立即用 `mysql --syntax-check` 或 Python sqlite3 兜底验证**（MySQL 8.0 CHECK 语法在 SQLite 中需改写为 TRIGGER）
4. **审核痕迹**：本次新增的审核修复（CHECK 约束、防爆破字段、匿名投递约束）均在第 4/5 章标注
5. **HTML 版本**：复用 `convert_tech_to_html.py` 改造，支持 SQL 块一键复制按钮
