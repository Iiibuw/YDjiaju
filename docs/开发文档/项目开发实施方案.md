## 1. 项目目标与一期范围

### 1.1 目标
交付一套**前后端分离**的企业家居官网系统：
- **前台展示系统**（React + Tailwind）：企业品牌展示、产品/案例/新闻/招聘/关于、在线预约、在线客服（关键词应答）、站内搜索、购物车与结算（部分商品）、会员中心。
- **后台管理系统**（React + Ant Design）：5 类角色 RBAC、细粒度权限 + 数据隔离 + 审计、轮播/产品/SKU/案例/新闻/招聘/关于/预约/留言/订单/系统管理。
- **后端 API**（FastAPI）：统一 `/api/v1`（前台）与 `/api/v1/admin`（后台）双路由。

### 1.2 一期范围（基于 PRD §2.4 / §10 + 技术文档 §0.4）
**包含**：前台全模块 + 后台全模块 + 移动端响应式 + 统计看板 + CMS 富文本 + 图片管理 + 部分商品在线下单（支付接口占位，二期对接）。
**不包含（Out）**：SEO 全套、完整会员营销（积分/优惠券）、生成式大模型 AI 客服、小程序/App 原生端、多语言*（见 §7-C 冲突）*。

### 1.3 非功能性（基于 PRD §7 + UI 文档 §55/§56）
- 移动端适配必做（UI 文档第十篇断点 lg=1024px）；
- 性能：首屏 < 3s、接口 p95 < 500ms（PRD §7.2）；
- 安全：JWT + 图形验证码 + 5 次锁定 + XSS 转义（PRD §7.3 / UI §49.4）；
- 验收：对齐 UI 文档 §56「交付前检查清单」。
