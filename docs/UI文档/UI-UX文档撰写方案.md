## 三、各篇章撰写要点

### 第一篇 · 基础与策略

**设计原则（6 条）**：
1. **品牌温润感** — 前台以 stone/sand 暖灰 + gold 金色点缀，传递家居品牌的温度与品质
2. **展示优先、线索为本** — 视觉重心在产品图与案例图，转化路径以预约/咨询留资为主
3. **前后台风格分离** — 前台 Tailwind 暖色优雅，后台 AntD 蓝色专业，各成体系
4. **角色驱动** — 后台按 5 类角色渲染菜单与权限，数据隔离
5. **移动端闭环** — 关键路径（浏览/预约/下单）在移动端完整可用
6. **渐进增强** — 动效尊重 `prefers-reduced-motion`，图片懒加载

**用户角色**：直接引用 PRD §3，前台 4 类用户 + 后台 5 类角色，每个角色配核心场景描述。

### 第八篇 · 交互与体验规范

- **hover 反馈**：导航下划线展开 / 卡片上浮 / 按钮变色，`transition-colors duration-200`
- **cursor-pointer**：所有可点击元素强制添加
- **状态反馈**：loading 禁用按钮 / skeleton 占位 / empty 空状态 / error 红色提示 / success toast
- **表单校验**：必填红星 + 失焦校验 + 错误信息就近显示
- **客服交互**：botAnswer() 关键词匹配（价格/预约/售后/地址/电话/人工）+ 快捷按钮 + 留资兜底
- **登录态**：localStorage 持久化 + 头像替换按钮 + 个人中心弹窗

---

### 第九篇 · 响应式与移动端

| 断点 | 宽度 | 布局变化 |
|------|------|---------|
| sm | ≥640px | 单列→双列 |
| md | ≥768px | 操作区显示 |
| lg | ≥1024px | 顶部导航完整显示 |
| xl | ≥1280px | max-w-7xl 容器 |

- 移动端导航：汉堡菜单 + 手风琴二级
- 触摸目标：≥44×44px
- 图片：自适应 + 懒加载
- 关键路径：浏览→预约→下单 移动端完整闭环

---

### 第十篇 · 可访问性与交付清单

- **对比度**：主文字 ≥4.5:1，大文字 ≥3:1
- **aria-label**：图标按钮必须有 aria-label
- **键盘导航**：Tab 顺序与视觉一致，焦点环可见
- **表单 label**：label for 关联
- **prefers-reduced-motion**：禁用所有动效
- **交付清单**：引用 ui-ux-pro-max Pre-Delivery Checklist（视觉/交互/明暗模式/布局/无障碍 5 类）
