## 二、前置条件

| 依赖 | 版本 | 说明 |
|---|---|---|
| Docker Desktop | ≥ 4.30 | Windows 需启用 WSL2 后端 |
| 可用内存 | ≥ 6GB | MySQL 1GB + 构建 2GB + 其他 |
| 磁盘 | ≥ 10GB | 镜像 + 数据卷 |

**安装**：https://www.docker.com/products/docker-desktop/ （下载后双击，勾选 WSL2，重启）

## 三、快速开始

### 3.1 安装 Docker Desktop（5 分钟）

> Windows **Home / Education** 用户也能装（只能跑 Linux 容器，本项目用的就是 Linux 容器，完全 OK）。

1. 打开 https://www.docker.com/products/docker-desktop/
2. 点击 **Download for Windows**
3. 双击 `Docker Desktop Installer.exe`
4. 安装选项勾选 **Use WSL 2 instead of Hyper-V**（推荐）
5. 重启电脑
6. 启动 Docker Desktop（托盘图标变绿色 = 就绪）

### 3.2 标准启动（6 服务全在 docker 内）

```bash
cd yd-furniture
./scripts/deploy.sh                # 等价于 docker compose up -d --build

# 看进度
docker compose -f docker/docker-compose.yml logs -f backend mysql
# 看到 backend: "Application startup complete" + mysql: "ready for connections" 即 OK
```

### 3.3 复用本机已有 MySQL（可选）

如本机已装 MySQL 8 想跳过 docker mysql：

```bash
cd yd-furniture/docker

# 1. 复制 override 模板
cp docker-compose.override.yml.example docker-compose.override.yml

# 2. 编辑 docker-compose.override.yml 里的 LOCAL_DB_HOST 等
#    Windows 上 DB_HOST 填 host.docker.internal（指向宿主 localhost）

# 3. 用 profile 跳过自带 mysql
docker compose --profile with-mysql up -d --build

# 4. 手动在本地 MySQL 执行 install_all.sql（首次需要）
mysql -uyd -p < ../../开发文档/数据库设计文档_install_all.sql
```

> Windows 也可：`docker compose -f docker/docker-compose.yml up -d --build`

## 五、数据初始化

MySQL 首次启动自动执行 `开发文档/数据库设计文档_install_all.sql`：
- 建库 `yd_furniture` + 全量 34 张表 + 触发器 + 视图 + 种子数据

## 六、常用运维

```bash
# 日志
docker compose logs -f backend
docker compose logs -f mysql

# 进入容器
docker exec -it yd-backend bash
docker exec -it yd-mysql mysql -uyd -pyd_secret_2026 yd_furniture

# 数据库备份
docker exec yd-mysql mysqldump -uyd -pyd_secret_2026 yd_furniture > backup_$(date +%F).sql

# 停止 / 重启
./scripts/deploy.sh down
./scripts/deploy.sh up

# 指定 JWT 密钥启动（生产必做）
JWT_SECRET=your-strong-secret ./scripts/deploy.sh
```

## 八、安全清单（上线前必做）

- [ ] 修改 `JWT_SECRET`（compose 内 `${JWT_SECRET}` 或 `.env`）
- [ ] 修改 MySQL root / yd 密码（compose `environment`）
- [ ] 验证码内存字典 → Redis（`auth_service.py` `_captcha_store` 注释处）
- [ ] `CORS_ORIGINS` 收紧为真实域名
- [ ] Nginx 加 HTTPS（certbot / 云厂商证书）
- [ ] `docker compose` 移除后台 `8000` 直连端口暴露（仅留 nginx 8080）

## 九、常见问题

| 问题 | 处理 |
|---|---|
| `port 3306 is already allocated` | 本机已有 MySQL，改 compose `ports` 映射（如 3307:3306） |
| `The compose file is invalid` | 用 `docker compose config` 校验 |
| 镜像拉取超时 | 配置镜像加速（`settings → Docker Engine` 加 registry-mirrors） |
| admin 页面白屏 | 确认访问 `/admin/`（带斜杠），且构建时 `base: /admin/` 生效 |
| 后端 500 db_ok=false | `docker compose logs mysql` 查初始化 SQL 是否报错 |
