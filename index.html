🎯 一分钟体验「前后端互通」

  1. 1. 打开「后台管理」→ 登录 → 「产品管理」→ + 新增一个产品（填名称/价格，分类可留空自动补）→ 保存
  2. 2. 打开「前台官网」→ 产品中心 → 硬刷新（Ctrl+Shift+R）→ 新产品出现（数据来自同一个数据库）
  3. 3. 回到本页刷新 → 上面「产品」计数 +1
  4. 4. 后台「订单管理」改状态 → 前台会员「我的订单」同步变化

🧩 技术架构

前端（单文件 SPA）

  • Tailwind CSS（CDN）
  • Hash 路由多页面
  • fetch 同源 /api/v1

后端（FastAPI）

  • FastAPI + SQLAlchemy
  • JWT + bcrypt 鉴权
  • RBAC 47 权限点 / 5 角色
  • 34 张表 / SQLite

桥接

  • 演示服务器（5280）
  • /api/* 反向代理 → :8000
  • 同源无跨域
